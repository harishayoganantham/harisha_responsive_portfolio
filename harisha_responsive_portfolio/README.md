# Harisha Yoganantham — Responsive Portfolio

Four-page personal portfolio built with semantic HTML5, CSS3, and vanilla JavaScript.

## Files
- `index.html` — Home
- `about.html` — About and skills
- `projects.html` — Project showcase
- `contact.html` — Contact form interface
- `assets/style.css` — CSS Grid, Flexbox, mobile-first breakpoints, CSS variables, themes
- `assets/script.js` — Theme toggle, mobile menu, form validation

## Run
1. Extract this ZIP.
2. Open the `harisha_responsive_portfolio` folder.
3. Double-click `index.html`.

No installation or build tools are needed.

## Personalise before publishing
- Replace `your.email@example.com` and add your actual social links in `contact.html`.
- Review and update the project descriptions and skill list.
- The contact form validates in the browser only; connect a backend or form service to receive messages.

## Included
- Responsive mobile/tablet/desktop layouts
- CSS Grid for page and card layouts; Flexbox for component alignment
- Light/dark theme toggle saved in browser storage
- Semantic landmarks, skip link, keyboard focus styles, labelled form fields
- Reduced-motion support and logical reading/tab order
